# COLD AI — голосовой помощник «Колд»

Android-приложение (Kotlin, Jetpack Compose, Room, Gemini API). Язык интерфейса: русский и украинский.

> **Статус проверки:** проект написан, но **не собирался** в этой среде (нет Android SDK). Первая сборка в GitHub Actions может показать ошибки компиляции. Если так, скопируйте текст ошибки из лога и передайте его — исправим.

## Что умеет
- Чат с Gemini в холодном стиле как у ChatGPT: тёмная тема, свободный текст ассистента, облачка пользователя.
- Кнопка **«Позвонить Колду»** — большая круглая кнопка голосового вызова (не телефонный звонок).
- Анимация «печатает» у ответа и волны, когда Колд слушает или говорит.
- Распознавание речи с исправлением «Каждое Слово С Большой Буквы».
- Озвучивание ответов, повторное озвучивание, копирование текста.
- Команды без ИИ: открыть приложение / сайт / настройки, время и дата, заряд батареи, таймер, поиск в Google, громкость, музыка (пауза, играй, следующий, предыдущий).
- Память (Room): история чатов, «Запомни, …», просмотр, удаление, очистка.
- Светлая и тёмная темы, планшетная раскладка (боковая панель от 840 dp).

## Убрано
- Телефонные звонки и SMS (школьный режим). Если попросить — Колд вежливо откажет.

## Примеры команд
«Открой youtube.com», «Открой настройки Wi-Fi», «Открой Telegram», «Который час?», «Какая сегодня дата?», «Пауза», «Следующий трек», «Громче», «Тише», «Поставь таймер 5 минут», «Найди теорема Пифагора», «Какой заряд батареи?», «Что ты умеешь?», «Запомни, что у меня урок в 10».

## Ограничения (честно)
- **Активация словом «Колд» в фоне не реализована.** Микрофон включается кнопкой «Позвонить Колду» и выключается при сворачивании приложения.
- Облачной синхронизации нет, все данные хранятся на устройстве.
- Ключ Gemini хранится через `EncryptedSharedPreferences`; в исходниках ключа нет.
- Gemini сам ничего на телефоне не выполняет. Действия делает только локальный модуль команд.
- Качество распознавания и наличие украинского/русского голоса зависят от сервисов Google на устройстве.
- Собирается только debug-APK.

## Gemini API
1. Получите бесплатный ключ: https://aistudio.google.com/apikey
2. В приложении: Настройки → Gemini API → вставьте ключ, при необходимости смените модель (по умолчанию `gemini-2.5-flash`) → Сохранить.

## Gradle wrapper
В архиве нет `gradle-wrapper.jar`, поэтому workflow запускает Gradle 8.7 через `gradle/actions/setup-gradle`.

## Как загрузить на GitHub с планшета и получить APK
1. На github.com создайте новый репозиторий, ветка `main`.
2. **Add file → Upload files** → загрузите ZIP и закоммитьте.
3. **Code → Codespaces → Create codespace on main**.
4. В терминале:
   ```
   unzip -o project.zip && rm project.zip
   git add -A && git commit -m "COLD AI" && git push
   ```
5. Вкладка **Actions** → артефакт **COLD-AI-APK** → установите `app-debug.apk`.
